<p>In this post, we share a simple recipe for reinforcement learning with agent swarms built on Context Language Models (CLMs)<span class="sidenote-wrapper"><label for="sn-intro-clm" class="margin-toggle sidenote-number"></label><input type="checkbox" id="sn-intro-clm" class="margin-toggle"/><span class="sidenote">Rulin Shao, Shannon Zejiang Shen, Junjie Oscar Yin, Yuetai Li, Minheng Wang, Hamish Ivison, Radha Poovendran, Nathan Lambert, Teng Xiao, Mike Lewis, Wen-tau Yih, Luke Zettlemoyer, and Pang Wei Koh. <a href="https://arxiv.org/abs/2609.37725">Context Language Models</a>. <em>arXiv preprint</em> arXiv:2609.37725, 2026.</span></span>, using TMax v1.1<span class="sidenote-wrapper"><label for="sn-intro-tmax" class="margin-toggle sidenote-number"></label><input type="checkbox" id="sn-intro-tmax" class="margin-toggle"/><span class="sidenote">Hamish Ivison, Junjie Oscar Yin, Rulin Shao, Teng Xiao, Nathan Lambert, and Hannaneh Hajishirzi. <a href="https://arxiv.org/abs/2606.23321">Tmax: A simple recipe for terminal agents</a>. <em>arXiv preprint</em> arXiv:2606.23321, 2026.</span></span> as the training data. CLMs naturally support multi-agent workflows by allowing multiple context files to coexist, leaving agents free to explore collaboration strategies without complex harnesses or predefined communication protocols.</p>
<p>We fully open-source our training infrastructure to make this recipe available for others to build on. Using TMax as an example training dataset, we train a five-agent CLM swarm with the same RL objective used in CLM. In this post, we walk through the setup, examine qualitative behaviors, and compare task performance before and after RL.</p>
<p>These experiments are preliminary. We share them as an initial baseline for future development, with the aim of making it easier to experiment with how agent swarms learn to collaborate.</p>

<h2 id="clms-make-agent-swarms-simple">CLMs Make Agent Swarms Simple</h2>
<p>Enabling a multi-agent swarm with CLMs is straightforward: <strong>a single configuration option allows multiple context files.</strong> CLMs already treat context as a file that the model can manage, so extending this abstraction to multiple files enables a swarm without a complex harness or a predefined communication protocol.</p>
<p>For our experiments, we enable five agents and adjust the prompt for the multi-agent setting. Each agent has its own editable context file. This setup is independent of training: the same context-file abstraction supports both a single agent and a swarm.</p>

<h2 id="training-clm-swarms-with-tmax-data">Training CLM Swarms with TMax Data</h2>
<p><strong>Stepwise RL with TITO.</strong> We treat each model call as a separate training segment. Through a <a href="https://huggingface.co/blog/huggingface/tito">token-in, token-out (TITO)</a> interface following Polar<span class="sidenote-wrapper"><label for="sn-polar" class="margin-toggle sidenote-number"></label><input type="checkbox" id="sn-polar" class="margin-toggle"/><span class="sidenote">Binfeng Xu, Hao Zhang, Shaokun Zhang, Songyang Han, Mingjie Liu, Jian Hu, Shizhe Diao, Zhenghui Jin, Yunheng Zou, Michael Demoret, Jan Kautz, and Yi Dong. <a href="https://arxiv.org/abs/2605.24220">Polar: Agentic RL on Any Harness at Scale</a>. <em>arXiv preprint</em> arXiv:2605.24220, 2026.</span></span>, we retain the exact input tokens and sampled output tokens for that call, and compute the policy loss on its generated tokens. Each segment preserves the context the model actually saw, even if later calls edit that context or use a different context file. The trainer consumes these token-level segments without needing to know how the harness constructed them. In a swarm, segments can originate from different agents' contexts; the same training procedure applies without changes to accommodate their source. This separates harness and communication-pattern design from the segment-level training interface.</p>
<p><strong>The RL objective.</strong> We train on <strong>TMax v1.1 data</strong> with the same RL objective used in CLM. Following the CLM paper's stepwise GRPO recipe, we sample a group of complete trajectories for each task, compute group-relative advantages from their final outcome rewards, and assign each trajectory's advantage to its constituent segments. The segments therefore learn from the outcome of the full task attempt.<span class="sidenote-wrapper"><label for="sn-clm-rl" class="margin-toggle sidenote-number"></label><input type="checkbox" id="sn-clm-rl" class="margin-toggle"/><span class="sidenote">See <a href="https://arxiv.org/html/2609.37725#S4.SS2">Context Language Models, §4.2: In-Context Learning and Reinforcement Learning for CLMs</a>, including Eq. (6) for the efficiency advantage.</span></span></p>
<p>The paper also defines a success-gated efficiency term, combining the advantages as:</p>
<div style="text-align: center; margin: 1.5em 0;" role="math" aria-label="A i equals A i outcome plus w efficiency times A i efficiency"><i>A</i><sub>i</sub> = <i>A</i><sub>i</sub><sup>out</sup> + <i>w</i><sub>eff</sub> <i>A</i><sub>i</sub><sup>eff</sup>.</div>
<p>Here, <i>A</i><sub>i</sub><sup>out</sup> measures task outcome; <i>A</i><sub>i</sub><sup>eff</sup> favors lower prefix-reuse FLOPs among successful trajectories. The efficiency term is zero for failed trajectories and for groups with fewer than two successes. For the swarm recipe here, we use the outcome-reward component; the efficiency extension is separate from this baseline.</p>
