<p>Context Language Models (CLMs) learn to manage their own context while solving tasks. What happens when several CLMs work on a task together? Can reinforcement learning help them become better collaborators?</p>
<p>We start with a CLM-initialized agent swarm and train it on TMax data using the same outcome reward as CLM. The recipe is simple: allow multiple context files to enable a CLM swarm, use five agents with an adjusted prompt, and run RL. Here we describe the setup and the questions we are investigating, with space for qualitative examples and a before-and-after evaluation.</p>

<h2 id="setting-up-a-clm-swarm-with-a-single-configuration-option">Setting Up a CLM Swarm with a Single Configuration Option</h2>
<p>Enabling a multi-agent swarm with CLMs is straightforward: <strong>a single configuration option allows multiple context files.</strong> CLMs already treat context as a file that the model can manage, so extending this abstraction to multiple files enables a swarm without a complex harness or a predefined communication protocol.</p>
<p>We initialize the swarm with CLMs, enable five agents, and adjust the prompt for the multi-agent setting. Five is the configuration we use in these experiments; the key change is allowing multiple context files. This gives us a simple starting point for studying how collaboration develops under RL.</p>
<p>The experiment asks a direct question: <strong>can task-level reinforcement learning improve how a group of CLMs solves problems together?</strong> The task outcome now reflects the behavior of several agents, so understanding their interactions is part of understanding the training process.</p>
<p>At a high level, the training loop takes a task from the training data, runs the multi-agent workflow, collects the resulting experience, evaluates the task outcome, and uses it for an RL update. The infrastructure has to connect the multi-agent rollout to the training loop.</p>
